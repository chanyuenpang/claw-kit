# 本地 beta 安装

1. 取用户指定批次的本地安装包，记录批次和版本；不用等 npm/GitHub 发布。
2. 安装 CLI 和当前宿主 adapter。Codex 批次可用 `npm run beta:install -- --candidate <目录>` 准备 CLI 和本地 marketplace，再通过宿主安装插件。
3. 确认 CLI 和插件版本符合该批次即可。无需逐文件检查、路径审计、cache 摘要或额外加载证据。

然后单独运行 scenarios.md 的冒烟场景。已有正确版本安装可直接测试。报告 beta 批次、版本和场景结果；修复代码后另打新批次再测，不把 beta 结果当成公开发布完成。冒烟不要求等满七天，也不负责上传或推送。

下文场景中的“公开/官方入口”在 beta 模式指该批次实际提供的入口。其余当前宿主路由和收口规则保持一致。
