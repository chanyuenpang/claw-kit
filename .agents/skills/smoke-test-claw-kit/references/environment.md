# 安装准备

1. 下载指定版本的 CLI 与当前宿主插件。默认从官方公开渠道获取；用户指定 beta 时取该批次的本地安装包，按 [beta 安装](beta-environment.md) 执行。
2. 按对应宿主的正常方式安装。CLI 使用指定版本，不以旧版本替代尚不可用的目标。
3. 确认 CLI 和插件版本一致于本轮目标。已有正确版本安装可直接使用；宿主要求重启才生效时按正常方式重启。

安装准备到此结束。不要求逐文件检查 installed/cache、依赖 realpath、摘要对照或专门的加载证明。下载或安装失败时按实际错误修复，仍不可用就报告具体原因，不用另一版本冒充成功。

随后通过当前真实 adapter 在当前项目执行 scenarios.md，使用唯一标识的专用测试计划。已有项目/session 即正常测试环境；不要求切换到仓库外、修改 cwd 或创建新 session。仅当用户要求或宿主正常支持时使用另一个测试项目。安装成功与冒烟结果分别报告；不要用模拟工具或另一个宿主代替当前 adapter。
