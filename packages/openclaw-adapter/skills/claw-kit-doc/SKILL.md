# claw-kit-doc

This is the OpenClaw adapter's documentation entry. It selects documentation
for the current request and does not perform updates or configuration
mutations.

- For updating claw-kit, read the **OpenClaw** section in
  `references/update.md` and use the OpenClaw plugin lifecycle that owns the
  active installation.
- For project configuration, read `references/configuration.md`.
- For Truth or ADR structure, read `references/knowledge-format.md`.

Read only the relevant reference. Keep release source, installed plugin, and
loaded skill snapshot as separate evidence.
