CLAW / CONFIGURATION

项目配置说明

claw-kit 不维护用户全局配置。配置只属于当前项目，避免跨宿主和跨仓库的隐式覆盖。

团队配置 .claw/project.json → 个人配置 .claw/project-override.json

团队配置

提交 .claw/project.json，用于团队共享的工作流、记忆、知识收尾和 GitNexus 设置。

{
  "planning": true,
  "goalMode": true,
  "memory": { "enabled": true }
}

个人配置

.claw/project-override.json 仅在当前工作区生效，默认被 Git 忽略；它自动覆盖同名团队字段，不应提交。

{
  "knowledgeWriter": { "reasoningEffort": "high" }
}

编辑与校验

使用编辑器修改对应 JSON；修改团队配置后运行 claw check 校验和规范化。数组会整体替换，个人层中的显式 null 是真实覆盖值。

更新 claw-kit

Cindy 不提供 claw-kit update skill。请按以下顺序操作：

  1. 打开插件页面
  2. 点击右上角“市场”
  3. 打开“已安装市场”并刷新 claw-kit 市场源
  4. 返回插件页面
  5. 在 claw-kit 插件项中确认更新

刷新市场只更新可用版本信息，不会自动安装插件更新。
