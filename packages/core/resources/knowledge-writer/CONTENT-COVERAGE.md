# Knowledge-writer contract coverage

- [TEMPLATE.json](<TEMPLATE.json>) owns two outcomes: coherent Truth/ADR governance, then verification and an honest result. Investigation and editing methods remain agent choices.
- [TEMPLATE.mjs](<TEMPLATE.mjs>) reuses that document and adds only configured retention and finalization context; it does not duplicate the task graph.
- [SKILL.md](<SKILL.md>) selects root or implicit-parent subplan entry. Session focus owns parent identity.
- [non-claw-fallback.md](<non-claw-fallback.md>) carries the same evidence, ownership, scope and result boundaries without procedural microsteps.
- [knowledge-format.md](<knowledge-format.md>) defines canonical state and dated evolution syntax for changed knowledge. Unrelated format migration is not required.
- The assignment builder inserts an external-document outcome before final verification when configured, preserving a real doc-updater subplan and the dependency on established knowledge.
- Canonical completion and knowledge receipts own refresh reconciliation. There is no manual index-preparation task.
- No-edit and partial results remain valid descriptions; unresolved required outcomes are not success. Known no-effect errors can be corrected, while accepted or unknown mutations are not replayed.
